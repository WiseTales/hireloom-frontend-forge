## [0.1.0] - 2026-02-18

### Added
- Initial repository specification following Spec-Kit schemas.
- Comprehensive `spec.json` defining the Talent Intelligence blueprint.
- Project Constitution and Implementation Plan.
- Supabase schema design for Skills Ontology (pgvector support).
- Edge Function skeletons for matching and agentic orchestration.
- React page skeletons for Dashboard, Sourcing, and Career Hub.
- GitHub Actions CI/CD workflow for automated deployment.
